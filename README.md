# Classificador de Raças de Cães

Sistema de classificação de raças de cães usando Deep Learning.

## Ferramentas Utilizadas

- **Python** - Linguagem principal
- **TensorFlow/Keras** - Framework de Deep Learning  
- **EfficientNet-B0** - Arquitetura do modelo
- **Transfer Learning** - Técnica de treinamento
- **OpenCV** - Processamento de imagens

## Dataset

- **30 raças** de cães
- **5.472 imagens** no total
- **Divisão**: 70% treino, 15% validação, 15% teste
- **Acurácia**: 91.11%
